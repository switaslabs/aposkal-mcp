Aposkal MCP Sunucusu

Resmî olmayan entegrasyon · Geliştiren: Switas Consultancy

Bu adreste, Aposkal muhasebe API'sini Claude gibi yapay zekâ asistanlarına bağlayan resmî olmayan bir MCP sunucusu çalışıyor. Token korumalı

Bu sunucu Aposkal'ın resmî ürünü değildir. Switas Consultancy tarafından geliştirilen bağımsız bir entegrasyondur ve Aposkal tarafından onaylanmamıştır.

Bağlantı adresi

MCP uç noktası: /api/mcp (Streamable HTTP).

Claude.ai: Settings → Connectors → Add custom connector yolundan bu adresin sonuna /api/mcp ekleyerek girin. Bağlanırken açılan sayfada sunucuyu kuran kişinin verdiği erişim parolasını yazın.

Claude Code:

claude mcp add --transport http aposkal https://BU-ADRES/api/mcp --header "Authorization: Bearer <token>"

Güvenlik

  • Erişim parolası ya da OAuth ile alınmış kısa ömürlü anahtar olmadan hiçbir araç çalışmaz.
  • Varsayılan mod salt-okumadır.
  • GİB'e ya da SGK'ya veri gönderen işlemler ayrıca açılmadıkça kapalıdır ve kullanıcı onayı (confirm) ister.
  • API anahtarları yalnızca sunucu ortam değişkenlerinde tutulur. Bu sayfada ya da yanıtlarda asla görünmez.
